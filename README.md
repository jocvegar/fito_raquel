# fitoraquel.com

Astro static site, deployed on Netlify.

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build
```

## Bitácora (Labor Legislativa / La Gorra Azul)

Each activity is one Markdown file in `src/content/activities/`, named
`YYYY-MM-DD-title.md`. The schema lives in `src/content/config.ts`; categories
and sections in `src/lib/activity.ts`.

Routes are generated from the `date` field, not from the file name:

- `/labor-legislativa/` and `/la-gorra-azul/`: month archive + latest entries
- `/<section>/<year>/<month>/`: the month, in chronological order, with category filter
- `/<section>/<year>/<month>/<slug>/`: one activity (its own URL and share preview)

Media is never committed to the repo:

- **Video**: `video.id` is a YouTube ID or URL (`provider: youtube`) or a
  Cloudflare Stream ID (`provider: cloudflare`). Only a thumbnail loads until
  the visitor presses play.
- **Photos**: `photos[].src` is a Cloudinary public ID or URL. Sizes and formats
  are generated by Cloudinary from the URL (`imageUrl` in `src/lib/activity.ts`).

### Environment variables

| Variable | Needed when |
| --- | --- |
| `PUBLIC_CLOUDINARY_CLOUD_NAME` | a photo uses a bare Cloudinary public ID |
| `PUBLIC_CLOUDFLARE_STREAM_CUSTOMER_CODE` | a video uses `provider: cloudflare` |

Set them in Netlify (Site configuration → Environment variables). The build
fails with a clear message if one is needed and missing.

### CMS

Decap CMS at `/admin/` (`public/admin/config.yml`). Saving an entry commits to
`master` and Netlify rebuilds. Login uses GitHub through Netlify's OAuth
provider; each editor needs write access to the repo. For local editing, run
`npx decap-server` alongside `pnpm dev`.
